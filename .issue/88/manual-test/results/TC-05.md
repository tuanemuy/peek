# TC-05: `/` キーによるフォーカスショートカット

## 手順と確認
1. `#sidebar-search` をクリア後、blur して main の h1 にフォーカス試行 → activeElement は BODY（input以外）
2. `/` を press
3. eval `document.activeElement.id` → `sidebar-search`
   - input 以外にフォーカスがある状態で `/` を押すと検索ボックスにフォーカスが移ることを確認
