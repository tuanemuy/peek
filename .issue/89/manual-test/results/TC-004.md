# TC-004: SSE ツリー更新時に開閉状態が維持される

- Issue: #89 (ファイルツリー折りたたみ状態の localStorage 永続化)
- 対象: SSE によるツリー更新時に開閉状態が壊れないこと
- 環境: http://localhost:3000 (peek directory モード, ライブリロード=SSE)
- 対象ディレクトリ: /tmp/peek-test-89
- セッション: verify-sse
- 実行日: 2026-06-07

## 結果: PASS

SSE によるツリー差し替え後も alpha の折りたたみが維持され、新規ディレクトリ newdir は展開状態で出現した。開閉状態（localStorage collapsed 集合, パスベース）はリセットされなかった。

## ステップ別判定

| # | 操作 | 期待 | 実際 | 判定 |
|---|------|------|------|------|
| 1 | http://localhost:3000 を開く / snapshot | ツリーが全展開で表示 | 7フォルダ全て expanded=true (alpha, sub-a1, sub-a2, beta, gamma, deep, deeper)。localStorage collapsed=[] | PASS |
| 2 | "alpha" を折りたたむ | alpha aria-expanded=false、子(sub-a1,sub-a2)非表示、collapsed に alpha 追加 | alphaExpanded=false、sub-a1 が DOM から消失 (NOT_IN_DOM)、collapsed=["alpha"] | PASS |
| 3 | newdir/new.md を追加し SSE 発火 | SSE 配信 | mkdir + echo 実行成功 | PASS |
| 4 | 4秒待機しツリー更新確認 | "newdir" と "new.md" が出現 | hasNewdir=true, hasNewMd=true, newdir aria-expanded=true | PASS |
| 5 | SSE 更新後の状態確認 | alpha 折りたたみ維持(false, 子非表示)、newdir はデフォルト展開 | alphaExpanded=false, subA1InDom=false, subA2InDom=false, collapsed=["alpha"], allButtons=[alpha=false, beta=true, gamma=true, deep=true, deeper=true, newdir=true] | PASS |
| 6 | newdir 削除 (SSE 再更新) | ツリーから newdir 消失、alpha は折りたたみ維持 | hasNewdir=false, alpha=false, collapsed=["alpha"] 維持 | PASS |
| 7 | セッション close | 正常終了 | Browser closed | PASS |

## localStorage 観測値

- 初期: `{"331492d18f68dc3f":{"collapsed":[],"lastAccess":1780763622053}}`
  - キーはディレクトリパスのハッシュ。collapsed は閉じている相対パス集合。
- alpha 折りたたみ後: `collapsed: ["alpha"]`
- SSE 更新(newdir 追加)後: `collapsed: ["alpha"]` (維持)
- SSE 更新(newdir 削除)後: `collapsed: ["alpha"]` (維持)

## 主要所見

- 開閉状態はパスベース (collapsed に相対パス文字列を格納) で localStorage に永続化されており、SSE による DOM 再描画後も alpha の折りたたみが正しく復元された。
- 折りたたみ時、子ノードは単に非表示ではなく DOM から除去される実装 (subA1InDom=false)。aria-expanded=false と整合。
- 新規 newdir は collapsed に記録が無いためデフォルト展開 (aria-expanded=true) で出現。仕様どおり。
- フォルダボタンには data-path 属性は無く、テキスト内容で識別。eval での確認は IIFE でラップする必要あり (eval コンテキストが const を保持し再宣言エラーになるため)。
