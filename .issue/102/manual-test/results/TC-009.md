## 【最優先】ライブリロードの切り分け結果

TC-001 実行者の観測（「`/01-headings.md` を開いた状態でファイルを編集しても DOM に反映されない」）は**再現した**。ただし切り分けの結果、**この PR の変更起因ではない**。原因は「ディレクトリモードで**ファイル URL に直接アクセス（ディープリンク）**した場合、SSE イベント受信後の再フェッチが `GET /api/content`（`path` パラメータ無し）になり 400 になる」という**変更前から存在する挙動**である。アプリ内でファイルツリーからファイルを開いた通常の導線では、変更後のビルドでライブリロードは正常に動作する。

| 変更後 × scratchpad fixture | `.../scratchpad/fixture` | ツリーから遷移 | ○ 反映（`SCRATCH-TOKEN-AFTER` が DOM に出現） | ○ `file-changed` / `tree-changed` 受信 | PASS |

| 変更後 × HTML ファイルモード | `$HOME/peek-tc009-lr/page.html` | `/` を開く | ○ iframe 内が `HTMLTOKEN-BEFORE` → `HTMLTOKEN-AFTER` に更新 | ― | PASS |

**結論**: **この PR 起因の回帰ではない**（既存の挙動）。根拠は次の 3 点。

1. **サーバー側のブロードキャストは両ロケーションで健全**。`curl -N http://localhost:3017/sse` / `:3018/sse` の生ストリームで、編集時に `event: file-changed` + `event: tree-changed`、ファイル追加/削除時にも同じイベント列が**scratchpad fixture・`$HOME` 配下の通常ディレクトリの双方で**流れることを実測した。`/private/tmp` シンボリックリンクによる監視挙動差は**無い**。
2. **ブラウザ側も通常導線では反映する**。ツリーからファイルを開いた状態（`location.pathname === "/view"`）で編集すると、本文が即座に差し替わり、ファイル追加でツリーに `TREEADD.md` / `ZZTREE.md` が現れ、削除で消える。HTML ファイルモードでも iframe が更新される。
3. **失敗するのはディープリンク時のみで、`origin/main` ビルドでも全く同じ**。`http://localhost:3018/a.md`（origin/main ビルド）でも DOM は更新されず、console には同じ `[peek] Failed to fetch content: HTTP 400` が出る。したがって PR の `/sse` ハンドラ変更（503 早期拒否・登録直後の再チェック・`clients.add` の `!closed` ガード・`node:timers/promises` 化）とは無関係。

**副次的な発見（この PR の範囲外・別 Issue 候補）**: ディレクトリモードでファイル URL に直接アクセスすると、SSE 受信後の再フェッチが `path` パラメータ無しの `GET /api/content` になり、`resolveAndValidatePath()`（`src/server/routes/api.tsx`）が `400 Missing path parameter` を返す。結果としてそのタブではライブリロードが機能しない。`src/client/hooks/use-sse-updates.ts` の `getCurrentPath` が未設定（file モード分岐に落ちている）ことが疑われる。**origin/main でも同一のため本 PR の修正対象ではない。**

## 失敗詳細

TC-009 の判定対象としての FAIL は無し。

参考として、切り分け中に確認した既存の不具合（本 PR 起因ではない）:

- **現象**: ディレクトリモードで `http://localhost:PORT/<file>.md` に直接アクセスしたタブでは、ファイル編集後もコンテンツが更新されない。
- **観測**: DevTools console に `[peek] Failed to fetch content: HTTP 400` が出る。`curl "http://localhost:3017/api/content"`（path 無し）は 400 `Missing path parameter`、`?path=a.md` は 200 を返す。
- **再現範囲**: 変更後ビルド・`origin/main` ビルドの双方で再現。scratchpad fixture・`$HOME` 配下の双方で再現。
- **関連コード**: `src/client/hooks/use-sse-updates.ts`（`getCurrentPath` 未設定時の file モード分岐）、`src/client/lib/api-client.ts` の `fetchContent()`、`src/server/routes/api.tsx` の `resolveAndValidatePath()`。
