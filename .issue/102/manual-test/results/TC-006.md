| 1-3 | SIGINT ×2、間隔 **20ms** | 同上 | exit=**0**、elapsed=**71ms**（うち 20ms は間隔）、`Force exiting...` **未出力**、警告 0 | PASS |

## 観測サマリー

| 項目 | 値 |
|---|---|
| 全試行数 | 7（EC1 ×4、EC3 ×1、EC4 ×2） |
| exit code | **全試行 0** |
| ハング（10 秒超）| **0 回** |

| `Force exiting...` 出力 | **0 回** |
| clack 枠の崩れ | 0 回 |

**エッジケース 1 の判定根拠**: testing.md は「**通常は `Force exiting...` は表示されず、exit code は 0 になる**」「**force exit に到達しないこと自体が、有界シャットダウンが効いている証拠**」「exit code が 0 で `Force exiting...` が出なかったことを『force exit 経路が壊れた』と判定しない」と明記している。実測は 4 通りの押下間隔すべてでこの記述どおりであり、**PASS と判定した**。

また testing.md は「この手順で毎回 `Force exiting...` が出る場合は 1 回目のシャットダウンが遅い＝真因が生きている疑い」としているが、**`Force exiting...` は 1 回も出ていない**ため該当しない。

**SSE 接続の有無で終了時間が変わらないこと**（EC4 の目的）も確認できた: SSE 1 本あり 40〜41ms / SSE なし 39ms / 一度接続して切断後 41ms と、差は計測誤差の範囲。
